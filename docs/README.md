# Legion Mob Arena - Leaderboard

This is the GitHub Pages website that displays the Legion Mob Arena global leaderboard.

## Setup Instructions

### 1. Enable GitHub Pages

1. Go to your repository settings
2. Navigate to "Pages" section
3. Under "Source", select "Deploy from a branch"
4. Select the branch (e.g., `main` or `claude/legion-mob-arena-plugin-01N4Fvu4VPbvVW9SogRS3qhY`)
5. Select the `/docs` folder
6. Click "Save"

Your leaderboard will be available at: `https://<username>.github.io/<repository-name>/`

### 2. Update Leaderboard Data

The leaderboard automatically updates from the `leaderboard.json` file in this folder. To keep it current:

**Option A: Manual Upload**
1. Locate the `leaderboard.json` file on your Minecraft server:
   - Path: `plugins/LegionMobArena/leaderboard.json`
2. Copy the file content
3. Update `docs/leaderboard.json` in this repository
4. Commit and push the changes

**Option B: Automated Script (Recommended)**

Create a script on your Minecraft server to automatically upload the leaderboard:

```bash
#!/bin/bash
cd /path/to/your/minecraft/server
cp plugins/LegionMobArena/leaderboard.json /path/to/repo/docs/leaderboard.json
cd /path/to/repo
git add docs/leaderboard.json
git commit -m "Update leaderboard data"
git push
```

Run this script via cron every 5-15 minutes for live updates.

**Option C: GitHub Actions (Advanced)**

You can set up GitHub Actions to automatically fetch the leaderboard data from your server if you expose it via an API or webhook.

## Features

- **Real-time Rankings**: Players sorted by highest round reached, then by total kills
- **Comprehensive Stats**: Displays games played, total kills, and gems earned
- **Top 3 Highlights**: Gold, silver, and bronze medals for the top 3 players
- **Auto-refresh**: Page automatically refreshes every 60 seconds
- **Responsive Design**: Mobile-friendly layout
- **Summary Statistics**: Shows total players, games, kills, and highest round achieved

## Files

- `index.html` - Main leaderboard page
- `styles.css` - Styling and design
- `script.js` - JavaScript for loading and displaying data
- `leaderboard.json` - Leaderboard data (auto-generated by plugin)

## Customization

You can customize the appearance by editing `styles.css`:
- Change colors in the gradient backgrounds
- Adjust fonts and sizes
- Modify the layout and spacing
